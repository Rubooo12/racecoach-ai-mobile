# racecoach-ai-mobile
Aplicación móvil de simracing para iRacing y Assetto Corsa. Consulta resultados, historial de carreras, tiempos por vuelta y progreso del piloto. Incluye análisis de frenada, aceleración y trazadas, con conexión segura a iRacing mediante OAuth y futura sincronización entre móvil y PC.
